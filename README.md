I build AI tools with a focus on local inference, persistent memory, retrieval, and desktop automation. My projects range from Linux assistants to multimodal search and applied machine learning.

Local-first is a design preference, not a blanket privacy guarantee: some projects use hosted models or external APIs. Each project's documentation describes its dependencies and setup.

## Selected projects

| Project | What it explores |
| --- | --- |
| [HyprAgent](https://github.com/San20506/hypragent) | A model-agnostic computer-use agent for Hyprland and Wayland, exposing desktop controls through MCP. |
| [media-memory](https://github.com/San20506/media-memory) | Ingestion and semantic search across images, video, audio, and documents using embeddings and ChromaDB. |
